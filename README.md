Al finalizar este curso serás capaz de:

- ✅ Programar con **PHP** desde cero
- ✅ Diseñar y gestionar **bases de datos** relacionales
- ✅ Trabajar con **MySQL** para almacenar y consultar información

## 🌐 ¿Cómo funciona una página web?

### Flujo general del sistema

```
USUARIO
   │
   ▼
FRONTEND  (HTML + CSS + JavaScript) → Lo que ve y usa el usuario
   │
   ▼
BACKEND   (PHP)                     → Procesa la lógica y conecta todo
   │
   ▼
BASE DE DATOS (MySQL)               → Guarda la información
   │
   ▼
RESPUESTA AL USUARIO
```

### Ejemplo paso a paso — Sistema de Zapatillas

| Paso | Descripción |
|:----:|---|
| 1️⃣ | Formulario de zapatilla (Frontend) |
| 2️⃣ | PHP recibe los datos |
| 3️⃣ | MySQL guarda la zapatilla |
| 4️⃣ | PHP consulta los productos |
| 5️⃣ | La página muestra las zapatillas |

> 💡 **En resumen:** el usuario interactúa, el **frontend** muestra, el **backend** procesa y la **base de datos** guarda.
